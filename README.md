# 🎮 Projeto de Extensão ODS 4 — Gamificação de Equações de 1º e 2º Grau

O projeto foi desenvolvido como uma atividade de extensão com o objetivo de tornar o aprendizado de matemática mais divertido para alunos do nível fundamental e médio. A proposta consiste na criação de atividades utilizando a plataforma Wordwall, por meio do modelo **“Abra a Caixa”**.

## 🕹️ Como Funciona?

As atividades foram divididas em níveis:

- 🟢 Fácil
- 🟡 Médio
- 🔴 Difícil

Cada questão possui:
- uma pergunta;
- alternativas de A até D;
- somente uma resposta correta.

OBS: As dificuldades são distribuidas de modo aleatório e espalhadas na tela.

## 🛠️ Ferramentas Utilizadas

- Wordwall
- GitHub
